## 🚀 Featured Project: ENAS for Image Classification

**Evolutionary Neural Architecture Search (ENAS)**  
_Accelerating neural network design for computer vision_

This project implements and extends ENAS for image classification, focusing on improving accuracy and computational efficiency using CIFAR-10 and CIFAR-100 datasets.

**Why is it cool?**  
Traditional NAS methods are resource-intensive and slow. My ENAS pipeline integrates pretrained backbones, progressive evolution, Hyperband tuning, and search-space pruning for faster, smarter architecture discovery.

### ✨ Key Contributions:
- **Enhanced ENAS Framework**: Combines aging evolution, weight sharing, and progressive search for better exploration and convergence.
- **Pre-trained Knowledge Transfer**: Integrates MobileNetV2 and custom deep CNNs as frozen backbones to speed up architecture search.
- **Search-Space Reduction**: Filters low-performing architectures to focus computation on high-potential designs.
- **Hyperparameter Optimization**: Uses Keras Tuner (Hyperband / RandomSearch) for efficient NAS exploration.
- **Scalable Evaluation**: Modular testing across CIFAR batches with performance visualization.
